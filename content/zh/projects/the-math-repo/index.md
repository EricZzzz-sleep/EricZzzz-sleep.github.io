The Math Repo 是一个全栈 Django Web 平台，用于竞技数学学习与题目归档。

- 实现可搜索题库，并支持按主题、难度与竞赛来源筛选。
- 设计基于 Markdown/JSON 的内容系统，用于 wiki 页面、题解与结构化题面。
- 使用 OpenAI API 集成 AI 辅导与聊天系统，提供具备上下文的数学辅助与对话式解题支持。
- 使用 Claude Code、Codex 与 GitHub Copilot 加速调试、功能原型设计和前后端整合。
