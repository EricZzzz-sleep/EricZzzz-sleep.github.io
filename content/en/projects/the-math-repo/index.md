The Math Repo is a full-stack Django web platform for competitive mathematics learning and problem archiving.

- Implemented a searchable problem database with filtering by topic, difficulty, and contest source.
- Designed a Markdown/JSON-based content system for wiki pages, editorials, and structured problem statements.
- Integrated an AI-powered tutoring and chat system using the OpenAI API with context-aware mathematical assistance.
- Used Claude Code, Codex, and GitHub Copilot to accelerate debugging, feature prototyping, and frontend/backend integration.
